# EMG Hand Rehabilitation Glove

An embedded healthcare rehabilitation project designed to assist finger movement using servo motor actuation. The glove uses selectable rehabilitation modes to control finger flexion and extension through five servo motors, with LED indicators for different assistance levels.

## Features
- Five-servo finger movement control
- Three rehabilitation assistance modes
- Push-button mode selection
- LED mode indication
- Finger open/close movement patterns
- Arduino-based embedded control

## Technologies Used
- Arduino Uno
- Servo Motors
- Embedded C / Arduino IDE
- Push Button
- LED Indicators
- Wearable Rehabilitation Glove

## Real-World Applications
- Stroke rehabilitation support
- Physiotherapy hand exercise assistance
- Finger mobility recovery training
- Home-based rehabilitation systems
- Assistive healthcare wearable devices
- Neuromuscular rehabilitation research
